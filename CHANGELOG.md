# Changelog

## 0.1.0-alpha

- Created the modular repository architecture.
- Split PSU, save-game and garage responsibilities.
- Migrated the validated Garage Tool V0.2 behavior into reusable modules.
- Added garage scanning, single-slot export, full export, slot import, append and full restore.
- Added basic save inspection, cloning, ASCII search and fixed-length replacement.
- Added project documentation and placeholder directories for saves, vehicles and assets.
